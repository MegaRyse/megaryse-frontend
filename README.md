# MegaRyse Website Templates

Three complete, standalone website templates for MegaRyse MBA Education Consultancy.

## Templates

### Template 1
- Location: `template1/`
- Design: Clean white background with gradient accents
- Run: `cd template1 && npm run dev`

### Template 2
- Location: `template2/`
- Design: Modern layout with professional gradient cards
- Run: `cd template2 && npm run dev`

### Template 3
- Location: `template3/`
- Design: Simple attractive design with color gradients
- Run: `cd template3 && npm run dev`

## Quick Start

Each template is a complete standalone project. To run a template:

1. Navigate to the template folder:
   ```bash
   cd template1  # or template2, template3
   ```

2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser to `http://localhost:5173`

## Features

All templates include:
- ✅ White background design
- ✅ Professional color gradients (Gold to Gold-bright)
- ✅ Responsive design (mobile-first)
- ✅ All pages: Home, About, Universities, Courses, Careers, Contact
- ✅ Framer Motion animations
- ✅ TypeScript support
- ✅ Tailwind CSS styling

## Project Structure

Each template folder contains:
- `package.json` - Dependencies and scripts
- `src/` - Source code
- `src/pages/` - Page components
- `src/components/` - Reusable components
- `.cursorrules` - Project-specific rules
- `README.md` - Template-specific documentation

## Notes

- Each template runs independently on its own port
- All templates use the same color palette but different layouts
- Templates are completely redesigned from reference websites (no similarity)
- Background images use placeholder emojis/icons
