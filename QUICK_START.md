# Quick Start Guide

## How to Run Each Template

Each template is a **complete standalone project** with its own dependencies and can run independently.

### Template 1

```bash
cd template1
npm install  # (already done)
npm run dev
```

Open: `http://localhost:5173`

### Template 2

```bash
cd template2
npm install  # (already done)
npm run dev
```

Open: `http://localhost:5173` (or next available port)

### Template 3

```bash
cd template3
npm install  # (already done)
npm run dev
```

Open: `http://localhost:5173` (or next available port)

## Design Differences

Each template has:
- **Different hero layouts** (split-screen, centered, etc.)
- **Different card styles** (rounded, shadow styles, borders)
- **Different section arrangements** (grids, columns, spacing)
- **Different animations** (fade, slide, scale)
- **Different typography treatments**

All maintain the same color palette but with unique visual presentations.
