# MegaRyse Template 2

A modern template with professional gradient cards and elegant spacing.

## Features

- White background design
- Gradient card layouts
- Modern spacing
- Clean design
- Responsive design
- All pages included

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The development server will start at `http://localhost:5173`

## Build

```bash
npm run build
```

## Pages

- `/` - Home
- `/about` - About Us
- `/universities` - Partner Universities
- `/courses` - Course Programs
- `/careers` - Careers
- `/contact` - Contact Form
